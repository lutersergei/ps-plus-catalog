# PS Plus Extra (Турция) — каталог игр с оценками

Дата: 2026-06-18

## Цель

Go-программа, которая:
1. Получает список всех игр каталога PS Plus Extra для региона Турция.
2. Для каждой игры добывает оценки Metacritic и OpenCritic.
3. Показывает данные на HTML-странице с пагинацией, фильтрами и сортировкой
   (по годам, жанрам, средним оценкам).

## Архитектура

Одна Go-программа с двумя подкомандами:

- **`sync`** — наполняет/обновляет SQLite-БД:
  - тянет каталог PS Plus Extra (TR) из внутреннего GraphQL-эндпоинта веб-стора
    PlayStation по ID категории PS Plus Extra;
  - для каждой игры добирает оценку OpenCritic (RapidAPI, по ключу) и Metacritic
    (скрейп страницы игры);
  - пишет результат в SQLite; уважает лимиты (троттлинг, backoff), уже собранные
    свежие оценки повторно не запрашивает.
- **`serve`** — HTTP-сервер на `localhost:8080`:
  - читает из SQLite, рендерит HTML через `html/template`;
  - фильтры (год, жанр), сортировка (год / средняя оценка / название) и пагинация
    реализованы **на сервере** через SQL, передаются query-параметрами
    `?genre=&year=&sort=&page=`.

Разделение `sync`/`serve` изолирует сеть и хрупкий скрейпинг от показа: сервер
быстрый и работает оффлайн на собранных данных.

**Стек:**
- стандартная библиотека: `net/http`, `html/template`, `encoding/json`, `flag`;
- SQLite — чистый Go-драйвер `modernc.org/sqlite` (без cgo);
- скрейп Metacritic — `net/http` + лёгкий парсинг (regexp / `golang.org/x/net/html`).

## Данные (SQLite)

Таблица `games`:

| поле | тип | источник |
|---|---|---|
| `id` | TEXT PK | concept/product id из PS Store |
| `title` | TEXT | PS Store |
| `release_year` | INTEGER | PS Store |
| `platforms` | TEXT | PS Store |
| `image_url` | TEXT | PS Store |
| `store_url` | TEXT | PS Store |
| `metacritic_score` | INTEGER NULL | скрейп MC (0–100) |
| `opencritic_score` | INTEGER NULL | OpenCritic API (0–100) |
| `average_score` | REAL NULL | среднее из доступных оценок |
| `scores_updated_at` | TIMESTAMP | для инкрементального обновления |

Жанры — в отдельной таблице-связке `game_genres(game_id, genre)`, чтобы фильтрация
по жанру и список доступных жанров шли чистым SQL.

`average_score` = среднее из имеющихся оценок (обе в шкале 0–100). Если оценок нет —
NULL; такие игры идут в конец при сортировке по оценке.

## Обработка ошибок и надёжность

- **Сопоставление игр с оценками** — по нормализованному названию. Неточно:
  при несовпадении логируем «не найдено» и оставляем оценку NULL, синк не падает.
- **Metacritic за Cloudflare** — при блоке/captcha логируем предупреждение,
  `metacritic_score = NULL`, продолжаем; UI показывает «N/A».
- **Лимиты API** — троттлинг между запросами + повтор с backoff на 429/5xx;
  свежие оценки (моложе N дней) повторно не запрашиваются.
- **Конфиг** — RapidAPI-ключ через переменную окружения `OPENCRITIC_API_KEY`,
  не в коде.

## Тестирование

По решению пользователя тесты откладываются до рабочего MVP. Код разбивается на
тестируемые единицы (парсеры на фикстурах, нормализация названий, расчёт
`average_score`, SQL-слой, HTTP-хендлер), чтобы тесты можно было добавить позже без
переделок.

## Объём MVP

Минимально рабочий результат: `sync` собирает каталог и хотя бы одну из оценок в
SQLite; `serve` показывает страницу с пагинацией, фильтром по году и жанру и
сортировкой по году/средней оценке/названию.
